# 拾遗 · 数字历史探索

《拾遗》是一门大学课程作业的 Web App MVP。它把传统展板式阅读，改成“进入场景 → 寻找线索 → 收集档案 → 解锁故事 → 对照复原”的沉浸式体验。

**重要说明：** 页面中的人物、地址、信件、剪报与故事全部是**演示内容**，不是真实史料。

## 如何在本地打开（推荐给零基础同学）

你不需要安装服务器，也不需要配置账号。

### 方法一：直接打开文件

1. 打开本文件夹。
2. 双击 `index.html`。
3. 网页会在浏览器中打开（建议使用 Chrome、Edge 或 Safari）。

### 方法二：在 Cursor 里预览

1. 用 Cursor 打开本项目文件夹。
2. 在左侧文件列表中找到 `index.html`，单击打开。
3. 右键点击编辑器中的 `index.html`，选择 **Open with Live Preview**（用实时预览打开）。
4. 如果没有该选项，也可以：
   - 按 `Ctrl + Shift + P`（Mac 为 `Cmd + Shift + P`）打开命令面板；
   - 输入 `Simple Browser` 或 `Live Preview`；
   - 选择用简易浏览器打开本地文件。
5. 也可以在 Cursor 终端里看到文件路径后，把 `index.html` 拖进 Chrome / Edge 窗口。

修改 `style.css` 或 `script.js` 后，刷新浏览器即可看到最新效果。

## 核心功能

- **首页**：产品名称、定位介绍、开始探索。
- **场景探索**：青岚巷数字沙盘，含 6 个可点击历史热点。
- **碎片收集**：照片、家书、口述、剪报、茶票、声音纪要。
- **历史档案馆**：已收集条目可再读，未收集条目保持锁定。
- **故事解锁**：集齐 6 件关键碎片后，解锁完整演示故事。
- **场景复原**：可拖动的“过去 / 现在”对照。
- **探索进度**：顶部显示已收集数量与完成百分比。
- **数据保存**：使用浏览器 `localStorage` 保存进度，刷新后不丢失。可在档案馆点击“重置探索进度”。

## 文件结构

```text
index.html   页面结构
style.css    视觉样式
script.js    交互与本地存储
README.md    说明文档
```

技术栈仅为 HTML、CSS、JavaScript。无需后台、无需 API Key、无需付费插件。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `shiyi`）。
2. 把本文件夹中的 `index.html`、`style.css`、`script.js`、`README.md` 上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**。
5. Branch 选择 `main`（或 `master`），文件夹选择 `/ (root)`，保存。
6. 等待一两分钟，页面会生成类似以下地址：

`https://你的用户名.github.io/仓库名/`

如果首页打不开，请确认 `index.html` 在仓库最外层，而不是放在子文件夹里。

## 使用建议

- 先从首页点“开始探索”，把巷中 6 个光点都点开并加入档案馆。
- 再进入“故事”查看解锁长文，最后到“场景复原”拖动对照轴。
- 本产品面向桌面浏览器完整使用，同时适配手机竖屏。
