# 拾遗·三星堆——古蜀文明沉浸式探索

《拾遗·三星堆》以四川广汉三星堆遗址为背景，把传统的展板式被动阅读，改造成“进入遗址 → 寻找线索 → 收集文物档案 → 拼接历史信息 → 解锁古蜀文明故事”的主动探索体验。

## 资料与内容说明

- 文物名称、出土年份、坑位、尺寸等信息，依据三星堆博物馆及权威媒体公开资料整理。
- 学界尚无定论的内容（如大立人像身份、神树含义、祭祀坑成因等）均以“推测”“尚无定论”明确标注。
- 页面中的图像全部为 AI 生成的氛围示意图，**并非文物实拍或遗址照片**，页面中已逐一标注。
- “推测性古代场景”为想象复原，不代表已证实的历史原貌。

## 如何在本地打开

你不需要安装服务器，也不需要配置账号。

### 方法一：直接打开文件

1. 打开本文件夹。
2. 双击 `index.html`。
3. 网页会在浏览器中打开（建议使用 Chrome、Edge 或 Safari）。

### 方法二：在编辑器里预览

1. 用编辑器打开本项目文件夹。
2. 找到 `index.html`，使用 Live Preview / Simple Browser 等预览功能打开。
3. 也可以把 `index.html` 直接拖进 Chrome / Edge 窗口。

修改 `style.css` 或 `script.js` 后，刷新浏览器即可看到最新效果。

## 核心功能

- **首页**：产品定位、探索命题与“进入遗址”入口。
- **遗址探索**：三星堆数字沙盘，含 6 个可点击探索热点。
- **文物档案**：青铜大立人像、青铜神树、金面具、青铜纵目面具、金杖、青铜太阳形器，每件含名称、图像、历史背景与相关线索。
- **文物档案馆**：已收集条目可反复研读，未收集条目保持锁定。
- **古蜀故事**：集齐 6 件文物档案后，解锁古蜀文明章节（学术推测均已标注）。
- **场景复原**：可拖动的“考古遗址现状 / 推测性古代场景”对照。
- **探索进度**：顶部实时显示已收集数量与进度条。
- **数据保存**：使用浏览器 `localStorage` 保存进度，刷新后不丢失，可在档案馆重置。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `shiyi-sanxingdui`）。
2. 把本文件夹中的 `index.html`、`style.css`、`script.js`、`README.md` 上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**。
5. Branch 选择 `main`（或 `master`），文件夹选择 `/ (root)`，保存。
6. 等待一两分钟，页面会生成类似以下地址：

`https://你的用户名.github.io/仓库名/`

如果首页打不开，请确认 `index.html` 在仓库最外层，而不是放在子文件夹里。

## 使用建议

- 先从首页点“进入遗址”，把现场 6 个光点都点开并加入档案馆。
- 再进入“古蜀故事”查看解锁章节，最后到“场景复原”拖动对照轴。
- 本产品面向桌面浏览器完整使用，同时适配手机竖屏。
